Python Arithmetic Operator Reference Guide
** Exponentiation

Raises left side to power of right side. e.g., 2**3 = 8

// Floor Division

Divides & rounds DOWN to nearest whole integer. e.g., 7//2 = 3

% Modulo

Returns the remainder of a division. e.g., 10%3 = 1

/ Float Division

Standard division (always returns a float). e.g., 5/2 = 2.5
